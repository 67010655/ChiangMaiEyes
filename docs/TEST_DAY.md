ทำก่อนเข้าฤดูไฟ (ม.ค.)

## ก่อนวันทดสอบ

- [ ] เว็บจริงเปิดได้ ข้อมูลไม่เก่า (ดูเวลาใต้ตัวเลขบนสุด)
- [ ] เตรียมบัญชีตัวแทนให้จิตอาสา: เขาสมัครเอง แล้วผู้ดูแลระบบอนุมัติในแท็บ "ตรวจคำขอ" (ตรวจชื่อ หน้าที่ และโทรยืนยันกับประธานป่าหรือเจ้าหน้าที่ก่อน)
- [ ] เพิ่มเพื่อน LINE `@241mevgs` ไว้ล่วงหน้าหรือให้เพิ่มในวันนั้น
- [ ] ลองในแอป LINE (เปิดลิงก์จากแชท) ด้วย ไม่ใช่แค่ Chrome หรือ Safari
- [ ] เตรียมกระดาษจด: เวลาที่ใช้ต่อข้อ ตรงไหนที่ลังเล คำพูดของผู้ทดสอบ

## วิธีทดสอบ

- ให้โจทย์ทีละข้อเป็นคำพูดธรรมดา **ห้ามบอกว่าต้องกดตรงไหน**
- จับเวลา: คนทั่วไปข้อละไม่เกิน 1 นาที ตัวแทนป่าข้อ 8 ไม่เกิน 1 นาที
- ถ้าเกินเวลาหรือถอดใจ ให้จดว่าไม่ผ่าน แล้วไปข้อต่อไป
- จดคำที่เขาพูดเองตอนงง เช่น "อันนี้คืออะไร" เพราะบอกได้ว่าคำหรือปุ่มไหนต้องแก้

## โจทย์: คนเชียงใหม่ 3 คน (ไม่เคยใช้เว็บนี้)

| ข้อ | โจทย์ที่พูด | ผ่านเมื่อ | ผล | เวลา | หมายเหตุ |
|---|---|---|---|---|---|
| 1 | "ใกล้บ้านคุณตอนนี้มีไฟไหม แล้วข้อมูลนี้เก่าแค่ไหน" | บอกได้ทั้งสองอย่าง | | | |
| 2 | "วันนี้ฝุ่นเป็นยังไง ออกนอกบ้านได้ไหม ค่านี้มาจากไหน" | บอกระดับ คำแนะนำ และแหล่งได้ | | | |
| 3 | "ถ้าเห็นไฟ ต้องโทรหาใคร" | ตอบ 1362 หรือหาเจอในเว็บ | | | |
| + | "ลองหาป่าชุมชนใกล้บ้าน แล้วส่งให้เพื่อนทาง LINE" | ส่งลิงก์ได้ เพื่อนเปิดแล้วเจอการ์ดป่า | | | |

## โจทย์: จิตอาสาป่าชุมชน (ดอยปุย 2–3 คน)

| ข้อ | โจทย์ที่พูด | ผ่านเมื่อ | ผล | เวลา | หมายเหตุ |
|---|---|---|---|---|---|
| 4 | "เข้าสู่ระบบ แล้วดูป่าของคุณ" | เห็นป่าของตัวเองเป็นหลัก | | | |
| 5 | "ตอนนี้มีไฟหรือความเสี่ยงใกล้ป่าไหม แล้วจะรู้ได้ยังไงถ้ามีไฟตอนกลางคืน" | อ่านสถานะได้ และเปิดแจ้งเตือน LINE หรืออีเมลได้ | | | |
| 6 | "ถ้ามีไฟใกล้ป่า ไฟน่าจะไปทางไหน" | บอกทิศลมและบอกว่าเป็นค่าประมาณ | | | |
| 7 | "ต้องติดต่อใคร" | เจอเบอร์หน่วยงานในพื้นที่และป่าข้างเคียง | | | |
| 8 | "สมมุติดับไฟเสร็จแล้ว ลองบันทึกเหตุ (ตำแหน่ง รูป ผล)" | บันทึกเสร็จภายใน 1 นาที | | | |

ข้อ 8 ให้ใช้ "ซ้อมใช้งาน" (อยู่ใน ป่าชุมชน → การแจ้งเตือน) ถ้าไม่อยากให้เกิดเหตุจริงในระบบ
