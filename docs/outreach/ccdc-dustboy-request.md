ผมยังไม่ได้ส่งอะไร

**ส่งถึง:** ศูนย์ข้อมูลการเปลี่ยนแปลงสภาพภูมิอากาศ (CCDC) มหาวิทยาลัยเชียงใหม่
**ช่องทาง** (จากหน้าติดต่อของ CCDC https://www.cmuccdc.org/contactus):
- อีเมล: หน้าเว็บซ่อนที่อยู่อีเมลไว้ ให้เปิดหน้านั้นในเบราว์เซอร์เพื่อดู
- Facebook: https://www.facebook.com/cmu.ccdc (ส่งข้อความหาเพจ)
- โทรศัพท์สำนักงาน: 06-4069-1698

**แนบไปด้วยได้:** ลิงก์เว็บ https://chiangmaieyes.vercel.app และภาพหน้าจอหน้าแผนที่กับหน้าวิเคราะห์

ข้อมูลที่ผมตรวจก่อนร่าง (21 ต.ค. 2026):
- รายชื่อสถานีที่ `https://www.cmuccdc.org/api/ccdc/stations` เปิดอ่านได้ มี 2,301 จุดทั่วประเทศ อยู่ในเชียงใหม่ 465 จุด ครบทั้ง 25 อำเภอ
- ค่าการวัดรายสถานี (`/api/ccdc/value/<id>`) ตอบว่า "Access denied" จึงต้องขออนุญาตก่อน
- รายชื่อสถานีมีอีเมลและเบอร์โทรของผู้ติดตั้งด้วย เราจะไม่เก็บและไม่แสดงข้อมูลส่วนนี้

**เรื่อง:** ขออนุญาตใช้ข้อมูล DustBoy ในเว็บไซต์ไม่แสวงกำไร ChiangMaiEyes

เรียน ศูนย์ข้อมูลการเปลี่ยนแปลงสภาพภูมิอากาศ (CCDC) มหาวิทยาลัยเชียงใหม่

ผม นายพีรยุตม์ วัฒนนวลสกุล ผู้พัฒนาเว็บไซต์ ChiangMaiEyes (https://chiangmaieyes.vercel.app) เว็บไซต์นี้ไม่แสวงกำไร ไม่มีโฆษณา และเปิดให้ทุกคนใช้ฟรี แสดงจุดความร้อนจากดาวเทียม ฝุ่น PM2.5 และทิศทางลมในจังหวัดเชียงใหม่ พร้อมข้อมูลรายป่าชุมชน 677 แห่ง เพื่อให้ประชาชนและตัวแทนป่าชุมชนใช้ติดตามสถานการณ์และประสานงานในช่วงฤดูไฟป่า

ปัจจุบันค่าฝุ่นบนเว็บมาจากสถานีกรมควบคุมมลพิษ ซึ่งในเชียงใหม่มีเพียง 2 สถานีในอำเภอเมือง จึงไม่สะท้อนพื้นที่อำเภอรอบนอกและพื้นที่ป่า ขณะที่ DustBoy มีจุดติดตั้งในเชียงใหม่ครบทุกอำเภอ ผมจึงขออนุญาตใช้ข้อมูล PM2.5 จาก DustBoy ดังนี้

1. **แสดงค่าปัจจุบันรายจุดบนแผนที่** พร้อมชื่อสถานี เวลาที่วัด และระบุว่าเป็นข้อมูลจาก DustBoy โดย CCDC มหาวิทยาลัยเชียงใหม่ ทุกครั้งที่แสดง
2. **สรุปค่ากลางรายอำเภอ** จากเครื่องที่ส่งข้อมูลล่าสุด เพื่อบอกประชาชนว่าฝุ่นในอำเภอของตนอยู่ระดับใด และแจ้งเตือนทาง LINE แบบสมัครเองเมื่อฝุ่นสูง
3. **แสดงค่าใกล้ป่าชุมชน** ในการ์ดของแต่ละป่า

ทางเราจะ:
- ให้เครดิต CCDC และ DustBoy ตามรูปแบบที่ศูนย์กำหนด และลิงก์กลับไปที่เว็บไซต์ของศูนย์
- ไม่เก็บและไม่แสดงข้อมูลติดต่อของผู้ติดตั้งเครื่อง (อีเมล เบอร์โทร ที่อยู่)
- ไม่นำข้อมูลไปขายหรือใช้เชิงพาณิชย์
- เรียกข้อมูลไม่ถี่เกินกว่าที่ศูนย์กำหนด และหยุดหรือปรับการใช้ทันทีหากศูนย์ต้องการ

ผมขอเรียนสอบถามเพิ่มเติม ดังนี้
1. ขั้นตอนการขอสิทธิ์หรือ API key เพื่ออ่านค่าการวัด และเงื่อนไขการใช้งาน
2. รูปแบบการให้เครดิตที่ศูนย์ต้องการ
3. ค่าที่ได้จาก API เป็นความเข้มข้น µg/m³ หรือค่า AQI และได้ปรับเทียบกับสถานีอ้างอิงแล้วหรือไม่
4. ความหมายของสถานะเครื่อง (เช่น `dustboy_status`, `db_status`) และควรถือว่าเครื่องที่ไม่ส่งข้อมูลนานเท่าใดเป็นข้อมูลเก่า
5. ความถี่สูงสุดที่ศูนย์อนุญาตให้เรียกข้อมูล
6. ศูนย์อนุญาตให้เก็บค่ารายวันไว้แสดงย้อนหลังได้หรือไม่ หรือให้แสดงเฉพาะค่าปัจจุบัน

หากศูนย์ต้องการข้อมูลเพิ่มเติมหรือต้องการให้ปรับวิธีการใช้ข้อมูล ผมยินดีปรับตามที่ศูนย์แนะนำครับ

ขอบคุณสำหรับข้อมูลและงานของศูนย์ที่ช่วยคนเชียงใหม่มาโดยตลอด
