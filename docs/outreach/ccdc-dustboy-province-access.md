# ตอบกลับ CCDC: ขอสิทธิ์ข้อมูล DustBoy ทั้งจังหวัดเชียงใหม่ (ร่างให้คุณส่งเอง)

ผมยังไม่ได้ส่งอะไร ส่งตอบในอีเมลเดิมที่ dustboy.3e@gmail.com ตอบมาได้เลย

**ทำไมต้องขอเพิ่ม:** หน้าเงื่อนไขของ open-api.cmuccdc.org เขียนว่าบัญชีประชาชนทั่วไปดึงได้สูงสุด 10 จุดติดตั้งต่อบัญชี
ถ้าเกินต้องติดต่อศูนย์เพื่อขออนุญาตเป็นกรณีพิเศษ แต่เชียงใหม่มี DustBoy 465 จุด ครบ 25 อำเภอ

**ก่อนส่ง:** สมัครบัญชีที่ https://open-api.cmuccdc.org/ ก่อน (ผมสมัครแทนไม่ได้) แล้วใส่อีเมลที่ใช้สมัครในจดหมาย

**เรื่อง:** Re: ขออนุญาตใช้ข้อมูล DustBoy · ขอสิทธิ์ข้อมูลรายจังหวัด (เชียงใหม่)

เรียน ศูนย์ประสานงานดัสบอย มหาวิทยาลัยเชียงใหม่

ขอบคุณมากครับสำหรับคำตอบและการอนุญาต ผมจะทำตามเงื่อนไขทุกข้อ ได้แก่ ระบุ "สนับสนุนข้อมูลโดย CCDC ม.เชียงใหม่" พร้อมโลโก้ DustBoy ทุกจุดที่แสดงข้อมูล ดึงข้อมูลชั่วโมงละไม่เกิน 1 ครั้ง เก็บไว้ในระบบของเรา และให้ผู้ใช้เรียกดูจากข้อมูลที่เก็บไว้แทนการเรียก API โดยตรง

ผมสมัครบัญชีที่ open-api.cmuccdc.org แล้วด้วยอีเมล [อีเมลที่ใช้สมัคร]

จากหน้าเงื่อนไขการใช้งาน บัญชีประชาชนทั่วไปดึงข้อมูลได้สูงสุด 10 จุดติดตั้ง ผมจึงขออนุญาตเป็นกรณีพิเศษ ดังนี้

1. **ขอสิทธิ์ใช้ API รายจังหวัด** (`/api/dustboy/province`) **สำหรับจังหวัดเชียงใหม่** เฉพาะจุดติดตั้งภายนอกอาคาร (Outdoor) เพื่อแสดงค่าฝุ่นครอบคลุมทั้ง 25 อำเภอ รวมถึงพื้นที่ป่าชุมชน
2. **การเรียกข้อมูล:** 1 ครั้งต่อชั่วโมง (คำขอเดียวได้ทุกจุดในจังหวัด) ต่ำกว่าเพดาน 10 ครั้งต่อชั่วโมงที่ศูนย์กำหนด
3. **การใช้ข้อมูล:** แสดงค่ารายจุดบนแผนที่ สรุปค่ากลางรายอำเภอ แสดงค่าใกล้ป่าชุมชน และแจ้งเตือนฝุ่นรายอำเภอทาง LINE แบบที่ประชาชนสมัครเอง เว็บไม่แสวงกำไร ไม่มีโฆษณา

ขอสอบถามเพิ่มเติม 1 ข้อครับ: นอกจากค่า TH AQI และ US AQI แล้ว API มีค่าความเข้มข้น PM2.5 (µg/m³) ด้วยหรือไม่ เพราะหน้าเว็บของเราแสดงค่าฝุ่นหลักเป็น µg/m³ ตามเกณฑ์กรมควบคุมมลพิษ และแยกค่าดัชนีไว้ต่างหาก
