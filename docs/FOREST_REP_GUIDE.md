# คู่มือตัวแทนป่าชุมชน: ใช้ ChiangMaiEyes ยังไง (ภาษาคน)

เขียนไว้สำหรับอธิบายปากเปล่า ตรวจกับโค้ดและหน้าเว็บ ณ 23 ต.ค. 2569 (หลังเพิ่มหมุดเหตุที่ตัวแทนแจ้ง)
เว็บ: https://chiangmaieyes.vercel.app

## เว็บนี้ทำอะไร (พูดได้ใน 20 วินาที)

> เว็บเป็นตัวช่วยดูสถานการณ์ ไม่ได้สั่งงาน
> ดาวเทียมเห็นความร้อนในป่า เว็บขึ้นจุดและแจ้งตัวแทนป่านั้นทาง LINE
> ตัวแทนไปดูของจริง ถ้าเห็นไฟ กด "บันทึกเหตุ" จะมี **หมุดรูปตา** ขึ้นบนแผนที่ให้ตัวแทนป่าทุกคนเห็น
> และระบบส่ง LINE ถึงป่าที่อยู่ใกล้ (ไม่เกิน 5 กม.) ให้โทรคุยกันเอง

**ที่ต้องรู้ก่อน (พูดให้ชัด):**
1. ดาวเทียมผ่านวันละ 5 ช่วง แล้วข้อมูลมาถึงเว็บช้าอีกราว 2–5 ชม. ไฟที่เพิ่งเริ่มจึง **ยังไม่ขึ้น** ได้ หมุดที่คนแจ้งจึงสำคัญ
2. จุดบนแผนที่ **ไม่ได้แปลว่าไฟไหม้จริง** ต้องมีคนไปดู
3. **เห็นควันหรือไฟจริง ให้โทร 1362 ก่อนเสมอ** ไม่ต้องรอเว็บ

## ใครเห็นอะไร

| คน | เห็นอะไร |
|---|---|
| ใครก็ได้ | แผนที่ จุดความร้อน ฝุ่น ลม และหน้าป่าชุมชน **ไม่เห็นหมุดเหตุ** |
| ตัวแทนป่าที่อนุมัติแล้ว | หมุดเหตุทุกป่า พร้อมชื่อผู้แจ้ง สิ่งที่เห็น เบอร์โทร (ถ้าผู้แจ้งใส่) และป่าใกล้จุดนั้น |
| ผู้แจ้ง | ทุกอย่างข้างบน และกด "จบงาน" ได้ |
| แอดมิน | เห็นทุกหมุด จบงานแทนได้ และอนุมัติคำขอตัวแทน |

ตัวแทนต้องรู้ว่า **ชื่อ ตำแหน่ง รายละเอียด และเบอร์ที่ใส่ จะถูกแสดงให้ตัวแทนป่าอื่นที่อนุมัติแล้วเห็น** (มีข้อความบอกในฟอร์มก่อนกดส่ง)

## ขั้นตอนของตัวแทนป่า (ทำครั้งเดียว)

1. **สมัครสมาชิก** กดรูปคนมุมขวาบน เลือก "สมัครใหม่" ใส่ชื่อ อีเมล รหัสผ่าน แล้วกดลิงก์ยืนยันในอีเมล (ดูจดหมายขยะด้วย)
2. **ไปเมนู "ป่าชุมชน"** ที่แถบล่าง
3. **ขอสิทธิ์ป่าของตัวเอง** พิมพ์ชื่อป่า เขียนว่าคุณมีหน้าที่อะไร แล้วกด "ส่งคำขอให้ผู้ดูแล" ยังไม่ได้สิทธิ์จนกว่าแอดมินอนุมัติ
4. **ผูก LINE** "การแจ้งเตือน" → "รับแจ้งเตือนทาง LINE" → เพิ่มเพื่อน → ส่งรหัส (ใช้ได้ 10 นาที ครั้งเดียว) → "ส่งรหัสแล้ว ตรวจสถานะ"

## เมื่อมีไฟ

1. **เห็นจุดไฟบนแผนที่ หรือ LINE เด้ง** กดดูตำแหน่ง และเวลาที่ตรวจพบ
2. **ไปดูของจริง หรือโทรถามคนใกล้จุดนั้น** อย่าเข้าไปดับไฟคนเดียว
3. **ถ้าเห็นไฟจริง โทร 1362** ก่อน
4. **กด "บันทึกเหตุ"** เลือกควันหรือเปลวไฟ ใช้ตำแหน่งตอนนี้ เล่าสั้นๆ ใส่เบอร์โทร (ไม่บังคับ) แล้วกดส่ง
   - ถ้ามีหมุดของคนอื่นอยู่ใกล้ (ไม่เกิน 2 กม. ใน 24 ชม.) ระบบเตือนก่อน ให้ติดต่อเขาเพื่อไม่แจ้งซ้ำ
   - ส่งได้ไม่เกิน 3 หมุดต่อวัน
5. **หมุดรูปตาขึ้นบนแผนที่** ตัวแทนป่าทุกคนเห็น และ **ป่าที่อยู่ห่างจุดไม่เกิน 5 กม. ได้ LINE** ทันที (กดลิงก์แล้วเห็นหมุดนั้น)
6. **ประสานงานกันเอง** โทรหาผู้แจ้ง (เบอร์ในหมุดและใน LINE) หรือคุยกับป่าข้างเคียง
7. **ไฟดับแล้ว ผู้แจ้งกด "จบงาน"** (หรือ "ไม่ใช่ไฟ") หมุดหายจากแผนที่ของทุกคน เก็บไว้ในประวัติเหตุของป่าผู้แจ้ง และป่าที่เคยได้ LINE ของหมุดนั้นจะได้ข้อความสั้นๆ ว่าปิดแล้ว
8. **ถ้าลืมกด** ระบบส่ง LINE เตือนผู้แจ้งวันละครั้ง และปิดหมุดให้เองเมื่อครบ 3 วัน

ถ้า **เห็นควันก่อนที่ LINE จะเด้ง** ให้ทำข้อ 3–4 ได้เลย ไม่ต้องรอ

## แอดมิน: อนุมัติตัวแทน

1. เข้าสู่ระบบ ที่แท็บ "ภาพรวม" ถ้ามี "คำขอรอตรวจ" กดเข้าไป (แท็บ "ตรวจคำขอ")
2. ดูชื่อ ป่าที่ขอ และหน้าที่ เช็คกับคนในชุมชนว่ารู้จักจริง (ตอนนี้ตัวแทนจะเห็นชื่อและเบอร์ของกันและกัน จึงควรเช็คทุกคน)
3. กดอนุมัติหรือไม่อนุมัติ พร้อมหมายเหตุ

ระบบตอนนี้มีสิทธิ์ 2 ระดับ คือ **แอดมิน (ทุกป่า)** กับ **ตัวแทนที่อนุมัติแล้ว** ยังไม่มีสิทธิ์ "ผู้ดูแลเฉพาะป่า"

## หน้า "ป่าของฉัน" บอกอะไรเพิ่ม

- **แถบสีส้ม "ยังไม่ได้ผูก LINE"** ขึ้นจนกว่าจะผูก (กดปุ่มไปหน้าผูก LINE)
- **การ์ด "มีรายงานไฟใกล้ป่าคุณ"** แสดงหมุดที่อยู่ในป่าคุณหรือห่างขอบเขตไม่เกิน 5 กม. มีปุ่ม "ดูบนแผนที่" และโทรหาผู้แจ้ง (ถ้าใส่เบอร์ไว้)
- **ป๊อปอัปหมุด** แสดง "ความคืบหน้าล่าสุด" จากบันทึกที่ป่าผู้แจ้งเพิ่ม (300 ตัวอักษรแรก ผู้เขียนจะเห็นข้อความเตือนว่าตัวแทนป่าอื่นเห็นด้วย)

## ที่ยังไม่พร้อม (บอกตรง ๆ ได้)

- **แจ้งเตือนเรื่องไฟมีทาง LINE ทางเดียว** อีเมลใช้เฉพาะเรื่องบัญชี (ยืนยันอีเมล เปลี่ยนรหัสผ่าน) ตัวแทนที่ไม่ผูก LINE จะไม่ได้ข้อความ แต่ยังเห็นหมุดบนแผนที่
- **ตอนนี้ผู้พัฒนาเป็นแอดมินคนเดียว** และอนุมัติตัวแทนทุกคนในช่วงทดสอบ เมื่อโครงการจบต้องโอนให้หน่วยงานที่รับช่วง (ดูท้ายคู่มือ)
- **จุดจากดาวเทียมช้าและพลาดไฟเล็กได้** ไฟที่เผาสั้น ๆ ระหว่างรอบอาจไม่ขึ้นเลย
- **LINE ฟรีมีโควตาข้อความต่อเดือน** แต่ละหมุดแจ้งไม่เกิน 10 ป่า
- **เมนู "ซ้อมใช้งาน" ถูกซ่อนไว้ก่อน** เพราะยังสอนขั้นตอนเดิม
- ข้อมูลส่วนบุคคล (ชื่อ อีเมล เบอร์ LINE) ยังต้องมีผู้ควบคุมข้อมูลตามกฎหมาย PDPA ก่อนใช้จริงในวงกว้าง

## คำถามที่น่าจะโดนถาม

- **ทำไมจุดไม่ขึ้นทั้งที่ผมเห็นควัน?** ดาวเทียมยังไม่ผ่าน หรือข้อมูลยังมาไม่ถึง เชื่อสิ่งที่เห็นก่อน โทร 1362 แล้วกด "บันทึกเหตุ" หมุดขึ้นทันที
- **ทำไมมีจุดแต่ไม่มีไฟ?** ดาวเทียมเห็นแค่ความร้อน อาจเป็นหินร้อน หลังคา หรือไฟเผาเสร็จแล้ว จึงต้องมีคนไปดู
- **ใครเห็นหมุดผม?** ตัวแทนป่าที่แอดมินอนุมัติแล้วทุกคน และแอดมิน คนทั่วไปไม่เห็น
- **ไม่อยากให้เห็นเบอร์?** ไม่ต้องใส่ เบอร์ไม่บังคับ
- **ลืมกดจบงานทำไงดี?** ระบบเตือนวันละครั้ง และหมุดหายเองใน 3 วัน แอดมินกดจบแทนได้
- **ใครกด "จบงาน" ได้?** คนที่แจ้ง กับแอดมิน
- **เสียเงินไหม?** ไม่เสีย
- **ถ้าผูก LINE แล้วไม่อยากรับ?** กด "ยกเลิกการผูก LINE" หรือบล็อกบัญชี จะหยุดส่ง

## โอนสิทธิ์แอดมินเมื่อโครงการจบ (สำหรับผู้พัฒนา)

สิทธิ์แอดมินคือแถวหนึ่งในตาราง `cme_admins` (คอลัมน์ `user_id`) ของ Supabase โปรเจกต์ ChiangMaiEyes ตรวจเมื่อ 23 ต.ค. 2569: มีแอดมิน 1 คน คือบัญชี peerayoot425@gmail.com

1. ให้คนรับช่วง **สมัครสมาชิกและยืนยันอีเมลในเว็บก่อน** (ระบบหา user_id จากอีเมลที่สมัคร)
2. **เพิ่มเขาเป็นแอดมินก่อน** (อย่าลบตัวเองก่อน):
   `insert into public.cme_admins(user_id) select id from auth.users where lower(email)='อีเมลของเขา';`
3. ให้เขาเข้าสู่ระบบ แล้วเช็คว่าเห็นแท็บ "ตรวจคำขอ"
4. ค่อยถอนสิทธิ์ตัวเอง (ถ้าต้องการ):
   `delete from public.cme_admins where user_id=(select id from auth.users where lower(email)='peerayoot425@gmail.com');`
5. โอนสิ่งที่ผูกกับบัญชีผู้พัฒนาด้วย: สิทธิ์เข้า Supabase, Vercel (2 โปรเจกต์), LINE Official Account, อีเมลผู้ส่ง (Resend) และกุญแจ API ทั้งหมด (ตั้งในหน้า Vercel โดยผู้รับช่วง ห้ามส่งผ่านแชท)
6. ควรมีแอดมินอย่างน้อย 2 คน เพื่อไม่ให้ระบบไม่มีคนอนุมัติ ถ้าคนเดียวหายไป
