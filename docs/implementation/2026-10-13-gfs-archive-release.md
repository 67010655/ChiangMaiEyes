# ChiangMaiEyes: คลังรอบแบบจำลอง GFS

วันที่ 13 ตุลาคม 2026 · ต่อจาก [งาน UX และสิทธิ์](2026-10-12-ux-and-permissions-release.md)

## สิ่งที่เพิ่ม

- แยกคลังแบบจำลอง GFS จากคลังค่าฝุ่นสถานีและจุดดาวเทียม เก็บทุกจุดกริด ค่าอ้างอิง หน่วย รอบแบบจำลอง เวลาที่ข้อมูลแทน และเวลารับจาก NOAA
- เก็บไฟล์ GRIB ต้นฉบับพร้อม SHA-256 ตรวจว่า hash ตรงกับไฟล์ก่อนเขียน และตรวจซ้ำด้วย constraint ฐานข้อมูล
- ฐานข้อมูลเป็นผู้กำหนด **เวลาบันทึกครั้งแรก** ไฟล์ที่ซ้ำไม่เขียนทับรายการเดิม ไม่ย้อนเวลาหลักฐานเมื่อรับซ้ำ และไฟล์ที่เปลี่ยน hash เก็บเป็นอีก revision
- อ่านคลังตามเวลาที่ระบบบันทึก ไม่ใช้เวลาแบบจำลองในอนาคตเป็นเวลา “รู้ข้อมูลแล้ว” API รองรับ `as_of` เพื่อแยกรอบที่ยังไม่เคยเก็บ ณ เวลานั้น
- หน้าแหล่งข้อมูลมีส่วนกดเปิด “ดูรอบ GFS ที่ระบบเก็บไว้” เลือกช่วง 7/30/180 วัน เปิดดูรอบที่เก็บพร้อมป้ายจากคลัง กลับข้อมูลรอบล่าสุดด้วยปุ่มเดิม
- เมื่อเปิดรอบจากคลัง เลื่อนและโฟกัสไปยังรายละเอียดที่เลือก รองรับ reduced motion และไม่ให้ข้อมูลสดที่ตอบช้าทับรอบจากคลัง
- API สาธารณะคืนเฉพาะข้อมูลวิทยาศาสตร์ ไม่มีข้อมูลบัญชี เหตุส่วนตัว อีเมล หรือ binary ภายใน ตารางและ RPC ใช้เฉพาะ service role ไม่เปิดให้สมาชิกเขียนเอง
- บันทึกหลังอ่านข้อมูลที่ตรวจสอบแล้ว การบันทึกล้มเหลวไม่ทำให้ค่าจาก NOAA กลายเป็นข้อมูลสมมติ และผู้ใช้ตรวจรายการที่บันทึกสำเร็จได้แยกกัน
- เตรียมการอ่านปัจจุบัน/+24/+48 เป็นรายชั่วโมงแยกนาที 15/20/25 เพื่อไม่เรียกต้นทางพร้อมกันทุกช่อง

## ผลทดสอบ

- Backend **204 ผ่าน** หลังแก้ test FIRMS เดิมให้ใช้เวลาคงที่ กรณีเดิมใช้วันปัจจุบันแต่กำหนดเวลาตรวจพบที่ยังมาไม่ถึงหลังเที่ยงคืน ไม่มีการลดเงื่อนไขกรองข้อมูลอนาคตของระบบ
- Frontend/SQL **107 ผ่าน** รวมการตรวจ hash, ไม่เขียนทับไฟล์ซ้ำ, จำกัดสิทธิ์, cutoff ที่ยังไม่รู้ข้อมูล, ป้องกัน response เก่าทับรอบที่เลือก, และข้อความคลังว่าง
- TypeScript และ build ผ่าน ยังมีคำเตือนขนาดไฟล์ MapLibre เดิม
- Migration ติดตั้งใน Supabase จริงแล้ว ก่อนอ่านข้อมูลพบ 0 frames และ `anonymous_direct_read=false`

## ขอบเขตหลักฐาน

คลังเริ่มเก็บเมื่อเปิดใช้งานวันที่ 13 ต.ค. ไม่อ้างว่ามี GFS ย้อนหลังครบ 180 วัน ช่วงวันใน UI เป็นช่วงค้นรายการที่เก็บสำเร็จ ไม่ใช่คำรับรองความครบทุกชั่วโมง

GFS เป็นแบบจำลองระดับภูมิภาค ไม่ใช่ค่าตรวจวัดในป่าหรือผลรับรองแบบจำลองไฟลาม ค่าสมมติด้านเชื้อเพลิง/ความชันในส่วนทดลอง และผลความแม่นยำภาคสนามยังต้องทำต่อ อีเมลสมาชิกทั่วไปยังต้องมีโดเมนผู้ส่ง/SMTP และรอบ Browser ยังติดข้อปฏิเสธสิทธิ์อัปโหลด/ดาวน์โหลดไฟล์จากระบบตรวจอนุมัติ

นิยามตัวแปรและหน่วยดู [NOAA GFS inventory](https://www.nco.ncep.noaa.gov/pmb/products/gfs/gfs.t00z.pgrb2.0p25.f000.shtml) และ [NCEP GRIB2 table](https://www.nco.ncep.noaa.gov/pmb/docs/grib2/grib2_doc/grib2_table4-2-0-3.shtml) ตารางเวลาและผลเก็บไฟล์เป็นหลักฐานของ ChiangMaiEyes ในรอบนี้ ไม่ใช่คำรับรองความครบหรือความแม่นยำจาก NOAA
