## กฎที่ห้ามทำลาย (Codex ต้องรักษา)
1. **ย้ายคำเตือน ไม่ลบ** ทุกตัวเลขต้องมีที่มาในแตะเดียว ผ่านปุ่ม ⓘ หรือ "รายละเอียด"
2. **ไม่เรียกจุดความร้อนว่าไฟที่ยืนยันแล้ว** และข้อมูลเก่าต้องดูเก่า (สีเทาหรือจาง)
3. **ไม่แสดงระดับเชื้อเพลิงที่ไม่มีแหล่งรองรับ** ระยะลามแสดงเฉพาะจุดอายุไม่เกิน 24 ชม. พร้อมคำว่า "ถ้ายังไหม้อยู่"
4. **เทสต์ที่คุมกฎเหล่านี้ต้องผ่านทุกครั้ง** ห้ามแก้เทสต์ให้หลวมลง: `landContext.test.ts`, `popupPresentation.test.ts`, `spreadHint.test.ts`, `publicGuidance.test.ts`, `navigationUi.test.ts`, `lineLink.test.ts`, `liveRefresh.test.ts`
5. **ทุกครั้งที่ปล่อย** เปิดแท็บใหม่บนเว็บที่ build แล้ว คอนโซลต้องไม่มี error เพราะสคริปต์ใน index.html ถ้าล้มจะทำให้ทั้งหน้าค้าง

- **กันสแปม:**
  - จำกัดจำนวนครั้งต่อเครื่องและต่อ IP เช่น 3 ครั้งต่อชั่วโมง โดยเก็บเฉพาะค่า hash ไม่เก็บ IP ดิบ
  - ใช้ระบบกันบอท Vercel BotID ที่ endpoint นี้ ไม่ใช้ CAPTCHA ให้คนกดแก้ภาพ
  - รายงานที่ถูกกด "ไม่พบ" ซ้ำ ๆ จากเครื่องเดียวกันให้ลดลำดับความสำคัญลง
- **ความเป็นส่วนตัว:**
  - ลบข้อมูล EXIF ในรูปออกเหมือนรูปเหตุเดิม (ใช้โค้ดเดียวกับ `incident_photo`)
  - พิกัดจริงและรูปให้เห็นเฉพาะตัวแทนที่ได้รับอนุมัติกับผู้ดูแล คุมด้วย RLS
  - ไม่ส่งพิกัดจริงลงไปในหน้าเว็บของคนทั่วไป ต้องปัดตั้งแต่ฝั่งเซิร์ฟเวอร์
- **โควตา LINE:** รายงาน 1 ครั้ง × ตัวแทนใกล้เคียง N คน = ใช้ N ข้อความ
  - ต้องจำกัดจำนวนตัวแทนที่รับต่อรายงาน เช่น 3 คนที่ใกล้ที่สุด
  - รายงานจุดเดียวกันซ้ำให้รวมเป็นข้อความเดียว
  - เมื่อโควตาหมด ให้แสดงในหน้า admin
- **ตอนยังไม่มีตัวแทนที่อนุมัติ** (ตอนนี้มี 0 คน): รายงานยังเก็บได้ แต่ไม่มีใครรับ หน้าเว็บต้องบอกผู้แจ้งตรง ๆ ว่า "ยังไม่มีตัวแทนในพื้นที่นี้ โปรดโทร 1362"
- **ตรวจรับ:**
  - แจ้ง 1 ครั้งต้องไม่ขึ้นบนแผนที่สาธารณะ
  - แจ้ง 2 เครื่องในรัศมี 1 กม. ภายใน 3 ชม. ต้องขึ้นบนแผนที่
  - ตัวแทนกดยืนยันแล้วต้องขึ้นบนแผนที่
  - ผ่าน 12 ชม. แล้วต้องหาย
  - API สาธารณะต้องไม่ส่งพิกัดจริง รูป หรือข้อมูลผู้แจ้งออกมา
  - แจ้งเกินจำนวนที่จำกัดต้องได้ 429 พร้อมข้อความภาษาไทย
  - เทสต์ของ backend และ RLS ต้องครอบคลุมทุกข้อข้างบน
- **ไฟล์:** migration ใหม่, backend/app/community.py (+ โมดูลใหม่), community_line.py, index.html (ฟอร์มแจ้ง), community-workspace.js (ปุ่มยืนยันของตัวแทน)
