# ChiangMaiEyes — ปรับ UX/UI ทั้งเว็บ (19 ต.ค. 2026)

เป้าหมาย: คนทั่วไปเปิดแล้วรู้ใน 3 วินาทีว่าควรดูตรงไหน ตัวแทนป่าทำงานได้โดยไม่ต้องอ่านยาว ทุกงานต้องช่วยเกณฑ์ 8 ข้อใน [PRODUCT_BRIEF.md](PRODUCT_BRIEF.md)

## กฎการออกแบบ (ใช้กับทุกหน้า)
1. **หนึ่งหน้าจอ ตอบหนึ่งคำถามก่อน** คำตอบ → ภาพ/สี → ตัวเลข → ที่มา (ที่มาอยู่หลังแตะเดียว ไม่ใช่บรรทัดยาว)
2. **ภาษาคนบนหน้าสาธารณะ** ไม่มี FRP, VIIRS, nominal, kernel density, AWS, CAMS, รหัสจุด บนหน้าแรก ย้ายไป "รายละเอียด" หรือ "สำหรับผู้เชี่ยวชาญ"
3. **สีมีความหมายเดียว** แดง = จุดไฟใหม่, ส้ม/เหลือง = เฝ้าระวัง, เขียว = ปกติ, เทา = ข้อมูลเก่า; ใช้ชุดเดียวทั้งเว็บ
4. **ปุ่มหลักปุ่มเดียวต่อหน้าจอ** หน้าสาธารณะคือ "โทร 1362"
5. **animation ต้องมีความหมาย** จุดใหม่กะพริบ จุดเก่าจาง ลูกศรลม ตัวเลขเปลี่ยนแบบนุ่ม ปิดเมื่อผู้ใช้ตั้ง reduced motion
6. **ความซื่อตรงของข้อมูลเหมือนเดิม** ทุกตัวเลขมีที่มาในแตะเดียว จุดความร้อนไม่ถูกเรียกว่าไฟที่ยืนยันแล้ว ข้อมูลเก่าต้องดูเก่า ไม่มีค่าที่ไม่มีแหล่งอ้างอิง
