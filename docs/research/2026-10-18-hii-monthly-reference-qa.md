# HII ตามรอยเผา: ตรวจหน่วยและข้อมูลตัวเลขสำหรับงานทดลอง

ตรวจจริง18ตุลาคม2026 งานนี้เพิ่มเฉพาะสคริปต์วิจัยและหลักฐาน ไม่มีการแก้หน้าเว็บ/deploy และไม่ใช้APIkeyจากเว็บอื่น

## ข้อสรุป

**ใช้ข้อมูลตัวเลขได้จริง ไม่จำเป็นต้องแกะสีจากภาพแผนที่:** เว็บทางการเชื่อมไปยังpublicdownloadของผลิตภัณฑ์B2F ซึ่งเป็นGeoTIFFรายเดือนของพื้นที่เขตป่าตามกฎหมาย ดาวน์โหลดตัวอย่างเชียงใหม่2กริดแล้วรวม2,643,406bytes และอ่านบนกริด20ม.ของกรณีทดลองได้จริง

แต่เหมาะเป็น **หลักฐานประกอบรายเดือน** มากกว่าคำตอบแนวไฟลามราย12ชั่วโมง: ข้อมูลไม่มีmaskยืนยันว่าทุกพิกเซลได้รับการสังเกตแบบฟ้าเปิด และผู้พัฒนาระบุว่าผลในเขตป่ายังไม่ได้รับการประเมินความถูกต้องอย่างเป็นทางการ วัตถุประสงค์และการตรวจภาคสนามเดิมเน้นพื้นที่เกษตรโล่ง [คำอธิบายผู้พัฒนา](https://tamroypao.hii.or.th/)

## GeoTIFFที่เข้าถึงได้จริง

จากลิงก์ดาวน์โหลดB2Fบนหน้าแรก เปิด[รายการปี2026](https://tamroypao.hii.or.th/product/B2F/2026/) ซึ่งแสดงTIFFรายMGRS และ[MB2Fปี2026](https://tamroypao.hii.or.th/product/MB2F/2026/)ที่แยกTIFFตัวเลขออกจากไฟล์ลงท้าย`_COLOR.tif` ไม่ใช้ไฟล์สีเป็นค่าclass

ตัวอย่างที่ดาวน์โหลด:

- [47QMAมีนาคม](https://tamroypao.hii.or.th/product/B2F/2026/BURNSCAR_47QMA_20M_202603_B2F.tif):1,278,633bytes
- [47QMVมีนาคม](https://tamroypao.hii.or.th/product/B2F/2026/BURNSCAR_47QMV_20M_202603_B2F.tif):1,364,773bytes

ตรวจRasterioได้ทั้งคู่:EPSG:32647,5490×5490พิกเซล,20×20ม.,1band,int16,LZW,ไม่มีoverviews,`nodata=None` ค่าที่พบมี0และ6000 โดยหน้าอธิบายผลิตภัณฑ์กำหนด6000เป็นรอยเผาในเขตป่าตามกฎหมาย ไฟล์100กม.ตามชื่อผลิตภัณฑ์มีขอบเขตจริงกว้าง109.8กม.ตามกริดSentinelจึงมีส่วนเหลื่อม ต้องunionmaskไม่บวกพื้นที่ซ้ำข้ามกริด

ทั้งสองไฟล์ตอบHTTPRange`bytes=0-15`ด้วย206และContent-Rangeตรงขนาดจริง แต่การรองรับRangeอย่างเดียวไม่พิสูจน์ว่าเป็นCOGที่เหมาะอ่านwindowอย่างมีประสิทธิภาพ รอบนี้ดาวน์โหลดเต็มเฉพาะสองไฟล์เล็ก ไม่โหลดทั้งประเทศ

Last-Modifiedเป็น2เมษายน2026หลังสิ้นเดือนมีนาคม จึงเป็นข้อมูลย้อนหลังสำหรับตรวจผล ไม่ใช่อินพุตที่มีอยู่ก่อนพยากรณ์ในเดือนมีนาคม และไม่ได้พิสูจน์วันเผยแพร่ครั้งแรก

`numeric-tiff-probe.json`เก็บchecksums,HTTPmetadata,CRS,transform,bounds,nodata,classesและcountsทั้งหมด

## ทดลองอ่านเข้ากรณีเดิมแล้ว

กรณี`2026-03-29`บนกรอบUTM47N `[468400,2080100,478400,2090100]`อ่านลงกริด500×500ที่20ม.ได้ **1,178พิกเซลบวก=.4712กม²** และกรอบrasterครอบคลุม100%ของwindow

คำว่าrasterครอบคลุม100%หมายถึงwindowอยู่ในextentไฟล์ ไม่ได้แปลว่ามีภาพฟ้าเปิด100% ไม่มีข้อมูลobservationcoverageจึงคืน`None`อย่างชัดเจน การพบรอยรายเดือนอาจเกิดก่อน29มีนาคมและไม่อาจยืนยันว่าเป็นไฟใหม่หลังเวลาเริ่มกรณี

สร้าง`backend/scripts/probe_hii_monthly_reference.py`:

```python
positive_mask, observation_coverage, receipt = read_case_monthly(
    meta, folder, month='202603', download=True
)
assert observation_coverage is None
```

สคริปต์ดาวน์โหลดสูงสุด3MBต่อไฟล์ด้วยHEADและboundedread;อ่านเฉพาะไฟล์ตัวเลข;nearest-neighborreprojection;ตรวจclass;unionส่วนเหลื่อม;เก็บhashและprovenance กรณีข้ามเดือนต้องร้องขอแต่ละเดือนโดยชัดเจน ไม่ถือเดือนเริ่มเป็นคำตอบตลอดช่วง

คำสั่งที่รันผ่านแล้ว:

```powershell
backend/.venv-research/Scripts/python -X utf8 backend/scripts/probe_hii_monthly_reference.py --local-only --case-id 2026-03-29 --month 202603
```

## สิ่งที่ใช้วัดได้และไม่ได้

- เปรียบเทียบยอดรอยไหม้รายเดือนเมื่อใช้ขอบเขตจังหวัดและขอบเขตป่าตามกฎหมายเดียวกัน พร้อมบอกความต่างของผลิตภัณฑ์
- ใช้positivepixelsเป็นหลักฐานประกอบว่ามีผู้ประมวลผลอีกชุดพบรอยที่ใดในเดือนนั้น หรือใช้หากรณีให้คนตรวจภาพเพิ่ม
- **ห้ามใช้0เป็นnonburnlabel**:ไม่ใช่maskแยกเมฆ/นอกป่า/ไม่พบรอยอย่างสมบูรณ์
- **ห้ามเรียกIoU/Diceกับmaskนี้ว่าaccuracyแนวไฟ12ชั่วโมง**:ช่วงเวลารายเดือนและขอบเขตต่างกัน รวมถึงยังไม่formalforestvalidated
- HIIใช้Sentinel-2เช่นเดียวกับreferenceของเรา จึงเป็นอีกกระบวนการประมวลผลแต่ไม่ใช่เซ็นเซอร์อิสระหรือgroundsurvey
- ขอบเขตป่าตามกฎหมายไม่ได้เท่ากับWorldCovertreecover/shrubหรือป่าชุมชน677แห่ง ห้ามเทียบยอดข้ามขอบเขตโดยไม่ตัดให้ตรงกัน

PublicTMScatalogที่ตรวจให้ชั้น`_COLOR`สำหรับแสดงผล แต่รอบนี้มีnumericB2Fที่เข้าถึงได้โดยตรง จึงไม่ต้องดาวน์โหลดtileสีหรืออนุมานค่าburnจากRGB การเข้าถึงpublicdownloadไม่ใช่หลักฐานสิทธิทุกแบบในการเผยแพร่ผลิตภัณฑ์ใหม่ รอบนี้ใช้เพื่อวิจัยออฟไลน์และเก็บแหล่งที่มา ไม่มีการสมัครหรือติดต่อผู้ใด
