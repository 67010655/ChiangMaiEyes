# พื้นที่อนุรักษ์ในการประสานงาน (PRODUCT_BRIEF ข้อ 7)

ตรวจแหล่งข้อมูล 19 ตุลาคม 2026 ใช้เพื่อบอกชื่อพื้นที่และช่องทางประสานงาน
ไม่ตีความอำนาจตามกฎหมาย ไม่มอบหมายงาน และไม่อนุญาตให้เข้าพื้นที่แทนเจ้าหน้าที่

## ต้นทาง สิทธิ์ใช้ และอายุข้อมูล

- [Thailand Protected Areas — Open Development Thailand](https://data.thailand.opendevelopmentmekong.net/en/dataset/thailand-protected-areas)
  ระบุวันที่อ้างอิง **2017-06-12**, Spatial Reference **EPSG:3857**,
  Use limitations: open government data, License **Other (Open)**, Copyright **Yes**.
- [รายการต้นทาง GISTDA](https://gistdaportal.gistda.or.th/portal/home/item.html?id=299b03fb814a49749cbedaca213a759b)
  เป็น lineage ที่ catalog ระบุ ไม่อ้างว่าเปิดตรวจเนื้อหา item นี้ได้สำเร็จ
- [GeoJSON WFS ที่ดาวน์โหลดจริง](https://data.opendevelopmentmekong.net/geoserver/ODMekong/ows?service=WFS&version=1.0.0&request=GetFeature&typeName=ODMekong%3AL10_ProtectedArea_MNRE_50k&outputFormat=application%2Fjson)
  มี 361 features, 38,449,577 bytes; `crs.properties.name=urn:ogc:def:crs:EPSG::3857`.
- Metadata API: `https://data.thailand.opendevelopmentmekong.net/api/3/action/package_show?id=thailand-protected-areas`
  ให้ `license_id=other-open`. สคริปต์หยุดหากสิทธิ์เปลี่ยน ไม่เปลี่ยนสิทธิ์ต้นทางเป็น CC0
  หรือใช้ CC BY-SA ใน footer ของเว็บไซต์แทนสิทธิ์ชุดข้อมูลนี้ รักษา attribution/ลิงก์ต้นทางไว้

เก็บไฟล์ที่สร้างใหม่ใน `frontend/public/protected-areas-chiangmai.geojson`
พร้อม SHA-256 ของไฟล์ WFS, ขอบจังหวัด, วันที่ตรวจ, สิทธิ์ใช้ และวิธีแปลงพิกัด
ไม่มีข้อมูลบุคคล และเว็บไม่เรียก WFS ขณะใช้งาน

## วิธีสร้างไฟล์ใหม่

ใช้ dependencies งาน offline ใน `scripts/requirements-terrain.txt`:

```powershell
backend/.venv/Scripts/python scripts/build_protected_areas.py
```

ถ้ามี cache ของ response WFS และ CKAN เดิมอยู่แล้ว ทำซ้ำแบบไม่ต่อเครือข่ายได้:

```powershell
backend/.venv/Scripts/python scripts/build_protected_areas.py --source C:/path/source.geojson --catalog C:/path/catalog.json --checked-on 2026-10-19
```

1. ตรวจ CRS ที่มากับ GeoJSON ต้องเป็น EPSG:3857 ไม่เปลี่ยนแค่ป้าย CRS
2. แปลงเป็น EPSG:4326 ด้วย PyProj และ `always_xy=True`
3. เลือก **21 features ที่ทับซ้อนขอบเชียงใหม่** แต่เก็บรูปร่างทั้งผืน
   ไม่ตัด polygon ตามเส้นจังหวัด เพราะจะสร้างขอบปลอมและทำให้ระยะถึงพื้นที่อนุรักษ์ผิด
4. ย่อรูปใน EPSG:32647 (UTM 47N, เมตร), preserve topology, เป้าหมาย 20 ม.
   ตรวจ Hausdorff distance ของผลที่ปัดพิกัดแล้ว ถ้าเกินงบให้ลด tolerance แล้วทำใหม่
   ผลชุดนี้ต่างจากรูปต้นทางสูงสุดประมาณ 20.27 ม. (งบ 20 ม. + ปัดพิกัดไม่เกิน 0.3 ม.)
5. ปัดพิกัด 6 ตำแหน่ง ตรวจความถูกต้องอีกครั้ง ไม่ซ่อม geometry ที่ผิดโดยเงียบ ๆ
   142,702 vertices เหลือ 34,260; ไฟล์ประมาณ 763 KB ก่อนบีบอัด

ระยะใน popup เป็นระยะเส้นตรงถึงขอบ polygon ไม่ใช่จุดกึ่งกลางหรือระยะเดินทาง
ใช้วิธีระยะถึงขอบเดียวกับการ์ดป่าชุมชน มีความคลาดเคลื่อนจากแผนที่เดิม/การย่อรูป
เงื่อนไขไม่เกิน 3 กม. เป็นเกณฑ์แสดงบริบท ไม่ใช่เขตปฏิบัติงาน

## ประเภทพื้นที่: หลักฐานและข้อจำกัด

ฟิลด์ `pro_type` ว่าง จึงไม่ใช้ฟิลด์นี้เป็นหลักฐาน และไม่พบคู่มือรหัส `pro_id`
ที่เผยแพร่โดยเจ้าของข้อมูลโดยตรง รอบนี้ใช้วิธี **เทียบชื่อที่รู้จัก** ตามที่เจ้าของงานอนุญาต:

| Prefix ในชุดปี 2017 | ประเภทที่ใช้ | ชื่อเทียบในไฟล์และหลักฐาน |
| --- | --- | --- |
| 1 | อุทยานแห่งชาติ | 1024 ดอยสุเทพ-ปุย, 1006 ดอยอินทนนท์ — [ตารางกรมอุทยานฯ หน้า 1](https://portal.dnp.go.th/DNP/FileSystem/download?uuid=8b378236-7cbe-4f50-81e4-c51d6f0115c4.pdf#page=1) |
| 2 | เขตรักษาพันธุ์สัตว์ป่า | 2019 เชียงดาว, 2026 อมก๋อย — ตารางกรมอุทยานฯ หน้า 1 เดียวกัน |
| 3 | เขตห้ามล่าสัตว์ป่า | 3003 ดอยสุเทพ, 3058 แม่เลา-แม่แสะ — ตารางกรมอุทยานฯ หน้า 1 เดียวกัน และ [บัญชีกรมอุทยานฯ บน data.go.th](https://data.go.th/dataset/dataset11_09) |
| 4 | วนอุทยาน | 4071 น้ำตกบัวตอง-น้ำพุเจ็ดสี — [กระทรวงการท่องเที่ยวและกีฬา](https://www.thailandtourismdirectory.go.th/th/attraction/3378), [การท่องเที่ยวแห่งประเทศไทย](https://thai.tourismthailand.org/Attraction/วนอุทยานน้ำตกบัวตองและน้ำพุเจ็ดสี) |

นี่เป็นการยืนยันจากการเทียบชื่อ ไม่ใช่การค้นพบคู่มือรหัสทางการ
สคริปต์ตรวจว่าชื่อเทียบและ prefix ยังตรงกันก่อนใช้ทั้งกลุ่ม ถ้าไม่ตรงให้ใช้เพียง
“พื้นที่อนุรักษ์ + ชื่อ” และเก็บ `type_method=unconfirmed` ไม่สร้างประเภทขึ้นมา
ในเว็บระบุชัดว่าเป็นประเภทในชุดปี 2017 และมีลิงก์หลักฐานประเภทพื้นที่

**ชื่อซ้ำไม่ใช่พื้นที่เดียวกัน:** ดอยสุเทพ (3003) แยกจากดอยสุเทพ-ปุย (1024)
และแม่เลา-แม่แสะมีทั้ง 2041 กับ 3058 ใช้ `pro_id` เป็นตัวระบุ ไม่รวม geometry ตามชื่อ
ถ้าพิกัดตรงหลายพื้นที่ แสดงทุกพื้นที่ที่ตรง ไม่ตัดสินเลือกผู้รับผิดชอบ

ตารางกรมอุทยานฯ ปี 2568 มีรายการที่สถานะ/ประเภทเปลี่ยนไปหรืออยู่ระหว่างเตรียมการด้วย
จึงใช้เอกสารนี้เทียบชื่อเท่านั้น ไม่ย้ายแนวเขตปี 2017 ให้เป็นแนวเขตหรือสถานะปัจจุบัน
การไม่พบในชุดนี้ไม่ยืนยันว่าอยู่นอกพื้นที่อนุรักษ์ทุกแห่ง

## การ์ด ตัวแทนป่า และช่องทางติดต่อ

- ภายใน polygon: ชื่อพื้นที่อนุรักษ์/กรมอุทยานฯ และตำบล/อำเภอขึ้นก่อนป่าชุมชน
- นอก polygon ไม่เกิน 3 กม.: “ห่างเขต… ประมาณ X กม.” แล้วเป็นป่าชุมชนใกล้เคียง
- ไกล/ไม่มีข้อมูล: คงการ์ดป่าชุมชนและกรมป่าไม้ พร้อมอธิบายสถานะของชั้นพื้นที่อนุรักษ์
- ใช้ **1362 สายด่วนกรมอุทยานฯ** เป็นหลักครั้งเดียวต่อการ์ด/หนึ่ง popup
  คงเบอร์กรมป่าไม้ในพื้นที่และ 052-081758 เป็นช่องทางสำรองตามงานเดิม
- ยังไม่เพิ่มเบอร์ที่ทำการอุทยาน: หน้า booking.dnp.go.th ที่ลองตรวจไม่สำเร็จ
  ไม่ยืนยันเบอร์จากเว็บรีวิว ที่พัก หรือผลค้นหาที่คัดลอกข่าวมาแทน
- ตัวแทนเห็นจุดดาวเทียม 24 ชม. ในพื้นที่อนุรักษ์ที่อยู่ไม่เกิน 5 กม. จากขอบป่าของตน
  รวมกรณีอำเภอเดียวกัน ไม่บังคับว่าป่าตนต้องใกล้ที่สุด พร้อมข้อความ
  “อยู่ในเขต… — ประสานเจ้าหน้าที่อุทยานก่อนเข้าพื้นที่” (ประเภทอื่นใช้เจ้าหน้าที่พื้นที่อนุรักษ์)
- เลเยอร์ขอบเขตในแผนที่ **2D ปิดเป็นค่าเริ่มต้น** ไม่เปลี่ยนค่าเปิด/ปิดชั้นป่าชุมชน
  popup 2D/3D ยังใช้การ์ดเดียวกัน แต่รอบนี้ไม่ได้เพิ่มเลเยอร์ polygon ในแผนที่ 3D

ทุกการแสดงผลที่ตรงพื้นที่มี “ขอบเขตจาก GISTDA 2017 ใช้อ้างอิง ไม่ใช่แนวเขตทางกฎหมาย”
ไม่เปลี่ยนการอนุมัติสิทธิ์หรือเผยข้อมูลติดต่อส่วนตัวต่อสาธารณะ ไม่มี migration
และไม่ deploy ในรอบงานนี้
